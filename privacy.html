隐私政策

本说明适用于 ZZZ-on 维护的个人自用 Codex Gmail CLI 配置。

访问与用途

通过用户授权的 Gmail API，本工具可访问账号身份资料，以及具体任务涉及的邮件、附件、线程、草稿和标签。数据仅用于用户明确要求的邮箱功能，例如查询、摘要、起草、发送及整理，不用于广告、出售数据或信用评估。

本机与第三方处理

gws 在用户电脑上执行，直接向 Google API 请求数据。OAuth 客户端配置保存在本机，授权令牌由 gws 加密保存并使用系统密钥存储。本配置没有另建用于集中存储邮件的服务器。

用户将 gws 交由 Codex 或其他 AI 助手执行时，任务需要的数据和命令输出可能提供给用户选用的助手服务，并保留在该服务的会话记录或用户保存的本地文件中。用户应按自身需要选择服务、控制任务数据范围和管理相关记录；不能将这种工作方式理解为邮件内容永不离开本机。

本应用对 Google API 数据的使用及向其他应用的传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。只在获得用户同意且为完成面向该用户的邮件功能所必需时向选用的助手服务提供相关数据，不授权将这些数据用于无关用途。

保存、撤销与删除

邮箱原始数据由 Google 保存。本地导出、缓存及助手会话记录的保存期限取决于用户操作和相应服务设置。用户可在 Google 账号的第三方连接设置中撤销本应用访问，并删除本机凭据、导出文件及相应助手记录。撤销授权不会自动删除原始邮件或已经保存的文件。

本说明网站

本静态网站不接收 Gmail 凭据或邮件，不设置统计脚本，也没有邮箱表单。GitHub Pages 主机可能为安全目的记录访客 IP，相关处理受 GitHub 隐私声明约束。

联系与变更

维护者为 ZZZ-on，仅服务账号持有人本人。若数据用途或共享范围发生变化，应先更新说明并重新取得必要的用户同意。
